# Задание

## Контекст

Это приложение `trainpay` для Webasyst: платёжная система присылает уведомление об оплате тренинга, клиент в личном кабинете видит свои оплаты и запрашивает возврат, сотрудник выгружает возвраты в CSV для бухгалтерии. Код сгенерировал AI-ассистент по задаче «сделай приложение оплат тренингов с возвратами». В прод он ещё не попадал.

Проект работает на **старой версии Webasyst**, поэтому решения должны использовать только стабильный API фреймворка без новых возможностей.

Твоя задача: **подготовить код к мержу**.

## Бизнес-требования

1. Видеть свои оплаты и запрашивать возврат могут **только авторизованные** клиенты, и только **свои** оплаты.
2. Уведомление платёжной системы принимается **только с верной подписью** (HMAC-SHA256 тела запроса, заголовок `X-Sign`). Секрет подписи не должен лежать в коде и попадать в логи.
3. Одно и то же уведомление (один `external_id`) обрабатывается **один раз**: доступ к тренингу открывается один раз, даже если платёжка прислала его дважды.
4. Сумма из уведомления **должна совпадать** с суммой оплаты в нашей базе.
5. Возврат возможен только для оплаты в статусе `paid`, **не позже 14 дней** после оплаты, **на всю сумму оплаты** (клиент её не задаёт) и **один раз**, даже при двух одновременных запросах.
6. Сотрудник видит оплаты и выгрузку возвратов **только с правом «Просмотр оплат»**. Выгрузка должна безопасно открываться в Excel.
7. Деньги хранятся и считаются **в копейках** (целые числа).

## Что нужно сделать

- Найти и исправить проблемы в PHP-коде, шаблоне и JS.
- Привести код в соответствие с бизнес-требованиями.
- Объяснить, как ты проверишь, что исправления работают.

Всё за 25 минут сделать не обязательно. Расставь приоритеты: начни с самого важного.
